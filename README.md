## 🌟 Core Conceptual Architecture

Instead of a generic portfolio with a static star background, this application places the visitor aboard a futuristic orbital telemetry recon vessel:
- **00. Command Bridge (Hero)**: Interactive 3D Recon Spacecraft featuring dynamic mouse roll/pitch banking, dual pulsing ion thruster plumes, rotating sensor radar, and atmospheric depth parallax.
- **01. Mission Profile (About)**: 3D Holographic Terrestrial Globe with orbital telemetry rings, pinpoint coordinates for Bhubaneswar (`20.29° N, 85.82° E`), and verified biometric engineering metrics.
- **02. Technology Galaxy (Skills)**: Real 3D interactive solar system with a central pulsing reactor core surrounded by 5 concentric orbits of tech nodes (Java, Spring Boot, Microservices/Kafka, AWS, MySQL, Angular/Mapbox) with live telemetry inspection.
- **03. Project Galaxy & Celestial Missions (Projects)**: 3 interactive celestial planets (Oceanic Cyber Planet, Golden Metropolis, Radar Grid) with warp camera transitions and comprehensive **Holographic Mission Dossiers** featuring interactive **System Architecture Pipelines**.
- **04. Space Flight Trajectory (Experience)**: Chronological vertical flight path with scrolling spacecraft waypoint marker detailing missions at **Cozentus** (Assistant Manager / Senior Java Developer) and **Ohhpro** (Full Stack Developer).
- **05. Academic Orbit & Credentials (Education)**: Constellation-styled credential cards for Utkal University (B.Sc.), Qspiders, and AWS Certified Developer – Associate.
- **06. Subspace Transmission Console (Contact)**: Cockpit communication console with audio frequency visualizer, instant clipboard copy for Email and Phone, and simulated encrypted transmission dispatch.
- **Subspace Audio Synthesizer**: Built with the native Web Audio API — real-time procedural space hum, hover blips, and warp engagement with a global audio mute toggle.

## 🛠️ Technology Stack

- **Graphics & 3D**: [Three.js](https://threejs.org/), [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber), [@react-three/drei](https://github.com/pmndrs/drei)
- **UI Framework**: [React 18](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/), Custom GLSL Shaders, Modern Glassmorphism
- **Animations**: [Framer Motion](https://www.framer.com/motion/), Native CSS Scroll Timelines
- **Audio**: Web Audio API (zero external audio file dependencies)
- **Build System**: [Vite](https://vitejs.dev/) with optimized vendor and Three.js chunk splitting

## 🚀 Quick Start

### 1. Install Dependencies
```bash

```

### 2. Launch Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
